CURRENT IMPLEMENTED FEATURES
- Two-page custom MPC skin: PLAY / SLICE SELECT and CHARACTER / SOUND DESIGN.
- 16 MIDI slices (notes 36–51), C4 selected-slice audition.
- Heuristic transient detection on sample load, with equal-slice fallback.
- Clean, Vintage and PAULA playback modes.
- Paula Hold, Linear and Cubic interpolation.
- PAULA-specific playback divider (1..6); not cycle-accurate hardware emulation.
- Vintage sample-hold rate reduction and bit-depth quantisation.
- 8-voice playback, reverse, pitch, low-pass and master level.
- Five factory presets, including Paula Jungle.
- Bundled original break WAV.

RECENT ENGINE WORK

- Added an ASan/UBSan regression test for the shared sample-hold phase.
- Added a PAULA-specific rate-divider range and an engine output regression test.
- Aligned vst.json plugin version metadata to 200 for 0.2.0.
